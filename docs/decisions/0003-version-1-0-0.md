# ADR-0003: The new app is version 1.0.0

- Status: Accepted (owner, 2026-11-14)
- Answers: PLAN.md §14 question 4

## Decision

The new app shows version **1.0.0** in Settings → Info (legacy shows `Versão: 0.9.1`, hard-coded in
`front-end/src/components/settings/legalInfo.jsx`). Everything else in the Info tab stays
as in legacy: "Webapp ERP", Software ID `69988ec8-c573-4799-bafc-0b6d30340961`, "2018, DIB4T".

## Consequences

- The version is set once in `Directory.Build.props` (`<Version>1.0.0</Version>`) and read at runtime from the
  assembly's informational version; it is not typed in the UI code. The same value is logged at startup (`App`
  category, §3.3).
- Later releases follow SemVer (1.0.x fixes, 1.x features).
